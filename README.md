# Modernization with GitHub Copilot

Welcome to the workshop! Three labs, one goal: make legacy code a little less legacy. You'll try three ways to modernize with GitHub Copilot and compare what each brings to the job.

| Lab | What you'll explore |
| --- | --- |
| [01 - GitHub Copilot upgrade](labs/01-copilot-upgrade/README.md) | Work through an upgrade of an existing .NET project. |
| [02 - Modernization CLI](labs/02-modernization-cli/README.md) | Take application modernization to the terminal. |
| [03 - Custom modernization plugin](labs/03-custom-plugin/README.md) | Package your company's modernization practices so teams can reuse them. |
