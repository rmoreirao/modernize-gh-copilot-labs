# Modernization with GitHub Copilot

Welcome to the workshop! Three labs, one goal: make legacy code a little less legacy. You'll try three ways to modernize with GitHub Copilot and compare what each brings to the job.

| Lab | What you'll explore |
| --- | --- |
| [01 - GitHub Copilot upgrade](labs/01-copilot-upgrade/README.md) | Work through an upgrade of an existing .NET project. |
| [02 - Modernization CLI](labs/02-modernization-cli/README.md) | Take application modernization to the terminal. |
| [03 - Custom modernization plugin](labs/03-custom-plugin/README.md) | Discover a C# API, generate reviewed HTTP characterization, and port it to Python/FastAPI with an agent and skills. |

**Lab 3 starter:** Clone the ordinary .NET Framework API from [rmoreirao/orderdesk-dotnet48](https://github.com/rmoreirao/orderdesk-dotnet48). The complete custom plugin stays in this workshop checkout; the agent generates characterization and the Python implementation in the separate application checkout during the exercise.
