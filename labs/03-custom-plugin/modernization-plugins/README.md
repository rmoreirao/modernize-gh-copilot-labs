# Central plugin repository

This is where a company would publish and maintain its shared modernization plugin. `centric-modernize` is the example plugin name; the skills are examples of practices a team could package.

```text
modernization-plugins/
|-- .github/plugin/marketplace.json
`-- plugins/centric-modernize/
    |-- plugin.json
    |-- agents/
    |   `-- centric-modernize.agent.md
    `-- skills/
        |-- target-architecture/
        |-- wcf-to-rest-api/
        |-- mvc-to-angular-webapi/
        `-- baseline-tests/
```
