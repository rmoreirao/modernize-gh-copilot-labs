# Lab 03: Custom modernization plugin

Build it once, share it with the team. This lab will explore how to turn your company's architecture standards and migration practices into a reusable GitHub Copilot plugin.

## Two repositories, two jobs

The workshop keeps both sides in this lab as sibling folders. They represent separate repositories in a real setup:

| Folder | Role |
| --- | --- |
| [Modernization plugins](modernization-plugins/README.md) | The central home for the marketplace, plugin, agent, and reusable skills. |
| [Your app](your-app/README.md) | The application being modernized, with its own upgrade artifacts and baseline tests. |

Each folder documents its proposed layout. The plugin and application aren't runnable yet.
